# アプリリリース完全フロー

## 📋 現在の状況

✅ **完了していること:**
- アプリ内課金（サブスクリプション）の実装が完了
- App Store Connectでサブスクリプション「VALVE プレミアム」を作成済み
- ローカリゼーションは「提出準備中」

⚠️ **対応が必要なこと:**
- App Reviewに「未解決の問題」がある（却下理由を確認する必要がある）
- サブスクリプションをアプリの新しいバージョンと一緒に提出する必要がある

## 🎯 次のステップ（優先順位順）

### ステップ1: 却下理由を確認する ⚠️ 最重要

**目的**: 以前の提出が却下された理由を確認し、修正する

**手順:**
1. App Store Connectにログイン
2. 「マイApp」→「VALVE」を選択
3. 左メニューから「**App Review**」をクリック
4. 「**未解決の問題**」の行（水曜日 1:06）をクリック
5. 却下理由の詳細を確認
6. 必要に応じて修正を実施

**確認すべき内容:**
- ガイドライン違反の内容
- 修正が必要な項目
- Appleからのメッセージ

---

### ステップ2: バージョン番号を更新する

**目的**: 新しいバージョンを作成して提出する準備

**手順:**
1. `pubspec.yaml`を開く
2. バージョンを更新:
   ```yaml
   version: 1.0.2+7  # 1.0.1+6から更新
   ```
3. 変更を保存

**現在のバージョン**: `1.0.1+6`
**新しいバージョン**: `1.0.2+7`（推奨）

---

### ステップ3: 新しいビルドを作成する

**目的**: アプリの新しいバージョンをビルドしてアップロードする

**手順:**

#### 3-1. クリーンビルド
```bash
cd /Users/ononono/soft-tennis-pj_frontend
flutter clean
flutter pub get
cd ios && pod install && cd ..
```

#### 3-2. iOSアプリをビルド（リリース用）
```bash
flutter build ipa --release
```

#### 3-3. Xcodeでアーカイブとアップロード
```bash
open ios/Runner.xcworkspace
```

Xcodeで:
1. デバイスを「**Any iOS Device (arm64)**」に設定
2. メニューから「**Product**」→「**Archive**」を選択
3. アーカイブ完了後、「**Distribute App**」をクリック
4. 「**App Store Connect**」を選択
5. 「**Upload**」を選択
6. オプションを確認して「**Upload**」をクリック

**所要時間**: 5〜15分程度

---

### ステップ4: App Store Connectで新しいバージョンを作成

**目的**: 新しいアプリバージョンを作成してサブスクリプションを紐付ける

**手順:**
1. App Store Connectにログイン
2. 「マイApp」→「VALVE」を選択
3. 左メニューから「**App Store**」をクリック
4. 「**+ バージョンまたはプラットフォーム**」をクリック
5. バージョン番号を入力: `1.0.2`
6. 「**作成**」をクリック

---

### ステップ5: サブスクリプションをバージョンに紐付ける

**目的**: サブスクリプションを新しいアプリバージョンに追加する

**手順:**
1. 作成したバージョン `1.0.2` のページを開く
2. ページを下にスクロール
3. 「**アプリ内課金とサブスクリプション**」セクションを探す
4. 「**+**」ボタンをクリック
5. 「**VALVE プレミアム**」を選択
6. 「**完了**」をクリック

---

### ステップ6: ビルドをバージョンに紐付ける

**目的**: アップロードしたビルドを新しいバージョンに割り当てる

**手順:**
1. バージョン `1.0.2` のページを開く
2. 「**ビルド**」セクションを探す
3. 「**+**」ボタンをクリック
4. アップロードしたビルドを選択
   - ビルドが表示されるまで数分〜数十分かかる場合があります
   - 表示されない場合は、少し待ってから「更新」ボタンをクリック

---

### ステップ7: 提出前の最終確認

**目的**: 提出前に必要な情報がすべて揃っているか確認する

**確認項目:**
- ✅ アプリの説明文が入力されているか
- ✅ スクリーンショットがアップロードされているか（iPhone、iPad）
- ✅ プライバシーポリシーURLが設定されているか
- ✅ 利用規約URLが設定されているか（アプリ内にリンクがある場合は不要）
- ✅ サブスクリプションがバージョンに紐付けられているか
- ✅ ビルドがバージョンに紐付けられているか

---

### ステップ8: 審査に提出する

**目的**: アプリとサブスクリプションを一緒に審査に提出する

**手順:**
1. バージョン `1.0.2` のページを開く
2. ページ右上の「**審査に提出**」ボタンをクリック
3. 確認ダイアログで内容を確認
4. 「**提出**」をクリック

**提出後:**
- 審査には通常1〜3日かかります
- App Store Connectから通知が届きます
- 「App Review」セクションで審査状況を確認できます

## ⚠️ 注意事項

1. **最初のサブスクリプション**: 必ずアプリの新しいバージョンと一緒に提出する必要があります
2. **ビルドのアップロード**: サブスクリプションを提出する前に、必ず新しいビルドをアップロードしてください
3. **却下理由の修正**: ステップ1で確認した却下理由を必ず修正してから提出してください
4. **審査時間**: 審査には通常1〜3日かかります。審査中はアプリの更新はできません

## 🆘 トラブルシューティング

### ビルドが表示されない
- ビルドのアップロードから表示まで数分〜数十分かかります
- 「ビルド」セクションで「更新」ボタンをクリックしてください

### サブスクリプションが選択できない
- サブスクリプションのステータスが「提出準備中」であることを確認してください
- ローカリゼーションが「却下済み」の場合は、まず修正してから提出してください

### 審査に提出できない
- すべての必須項目が入力されているか確認してください
- ビルドとサブスクリプションがバージョンに紐付けられているか確認してください
