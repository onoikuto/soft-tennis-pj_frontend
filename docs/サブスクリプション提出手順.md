# サブスクリプション提出手順

## 現在の状況

- **サブスクリプションのステータス**: デベロッパの対応が必要
- **ローカリゼーションのステータス**: 提出準備中（却下ではない）
- **問題**: 最初のサブスクリプションは、アプリの新しいバージョンと一緒に提出する必要がある

## 解決方法

サブスクリプションを提出するには、**アプリの新しいバージョンと一緒に提出**する必要があります。

### ステップ1: アプリの新しいバージョンを作成

1. **App Store Connectにログイン**
   - https://appstoreconnect.apple.com/

2. **「マイApp」→「VALVE」を選択**

3. **新しいバージョンを作成**
   - 左メニューから「**App Store**」をクリック
   - 「**+ バージョンまたはプラットフォーム**」をクリック
   - 新しいバージョン番号を入力（例: `1.0.2`）
   - 「**作成**」をクリック

### ステップ2: サブスクリプションをバージョンに紐付け

1. **アプリバージョンページを開く**
   - 作成した新しいバージョンを選択

2. **「アプリ内課金とサブスクリプション」セクションを開く**
   - ページを下にスクロール
   - 「**アプリ内課金とサブスクリプション**」セクションを探す

3. **サブスクリプションを選択**
   - 「**+**」ボタンをクリック
   - 「**VALVE プレミアム**」を選択
   - 「**完了**」をクリック

### ステップ3: ビルドをアップロード

1. **Xcodeでアーカイブを作成**
   ```bash
   cd /Users/ononono/soft-tennis-pj_frontend
   flutter build ipa --release
   ```

2. **Xcodeでアーカイブとアップロード**
   ```bash
   open ios/Runner.xcworkspace
   ```
   - Xcodeで「Product」→「Archive」を選択
   - アーカイブ完了後、「Distribute App」をクリック
   - 「App Store Connect」を選択
   - 「Upload」を選択してアップロード

3. **または、Transporterアプリを使用**
   - Transporterアプリを開く
   - 作成した`.ipa`ファイルをドラッグ&ドロップ
   - 「配信」をクリック

### ステップ4: アプリバージョンにビルドを紐付け

1. **App Store Connectでアプリバージョンページを開く**
   - 「マイApp」→「VALVE」→「App Store」→ 作成したバージョンを選択

2. **ビルドを選択**
   - 「**ビルド**」セクションで、アップロードしたビルドを選択
   - ビルドが表示されるまで数分〜数十分かかる場合があります

### ステップ5: 審査に提出

1. **提出前の確認**
   - アプリの説明文が入力されているか
   - スクリーンショットがアップロードされているか
   - プライバシーポリシーURLが設定されているか
   - 利用規約URLが設定されているか（アプリ内にリンクがある場合は不要）

2. **審査に提出**
   - ページ右上の「**審査に提出**」ボタンをクリック
   - 確認ダイアログで「**提出**」をクリック

## 注意事項

- **最初のサブスクリプションのみ**: 最初のサブスクリプションは必ずアプリバージョンと一緒に提出する必要があります
- **2回目以降**: 一度提出して承認されれば、以降のサブスクリプションは単独で提出できます
- **ビルドのアップロード**: サブスクリプションを提出する前に、必ず新しいビルドをアップロードしてください

## 現在のバージョン情報

- **現在のバージョン**: `1.0.1+6`（`pubspec.yaml`より）
- **推奨**: 新しいバージョン `1.0.2+7` を作成して提出

## トラブルシューティング

### ビルドが表示されない
- ビルドのアップロードから表示まで数分〜数十分かかります
- 「ビルド」セクションで「+」ボタンをクリックして、利用可能なビルドを確認してください

### サブスクリプションが選択できない
- サブスクリプションのステータスが「提出準備中」であることを確認してください
- ローカリゼーションが「却下済み」の場合は、まず修正してから提出してください
