# 利用規約公開手順

App Store審査で必要な利用規約（EULA）をGitHub Pagesで公開する手順です。

## 手順

### 1. ファイルの確認

以下のファイルが作成されていることを確認してください：
- `docs/terms_of_service.html` - 利用規約のHTMLファイル

### 2. GitHubにプッシュ

```bash
# 変更をステージング
git add docs/terms_of_service.html docs/利用規約公開手順.md

# コミット
git commit -m "Add Terms of Service (EULA) page"

# プッシュ
git push origin feature/soft_tennis_pj_ph1
```

### 3. GitHub Pagesの確認

プッシュ後、数分待ってから以下のURLにアクセスして確認してください：

**利用規約URL:**
```
https://ononono.github.io/soft-tennis-pj_frontend/docs/terms_of_service.html
```

### 4. App Store Connectでの設定

1. App Store Connectにログイン
2. アプリを選択
3. 「App情報」→「一般情報」を開く
4. 「利用規約（EULA）」の欄に、上記のURLを入力
5. または、「App Store」→「バージョン情報」→「説明」の最後に利用規約へのリンクを追加

**説明文への追加例:**
```
[アプリの説明文]

利用規約: https://ononono.github.io/soft-tennis-pj_frontend/docs/terms_of_service.html
```

### 5. アプリ内リンクの確認

アプリ内のサブスクリプション画面に利用規約へのリンクが追加されていることを確認してください。

## 注意事項

- GitHub Pagesの反映には数分かかる場合があります
- URLが正しくアクセスできることを必ず確認してください
- アプリ内のリンクが正しく動作することを確認してください
