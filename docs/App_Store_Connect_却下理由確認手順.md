# App Store Connect サブスクリプション却下理由確認手順

## 方法1: サブスクリプション詳細ページから確認（推奨）

1. **App Store Connectにログイン**
   - https://appstoreconnect.apple.com/ にアクセス
   - Apple Developerアカウントでログイン

2. **アプリを選択**
   - 「マイApp」をクリック
   - 「VALVE」アプリを選択

3. **アプリ内課金ページを開く**
   - 左メニューから「**アプリ内課金**」をクリック
   - 「**サブスクリプション**」タブを選択

4. **サブスクリプションを選択**
   - 「**VALVE プレミアム**」をクリック

5. **ローカリゼーションの詳細を確認**
   - 「ローカリゼーション」セクションで「日本語」の行を確認
   - 「却下済み」の横に「**詳細**」や「**i**」アイコンがある場合はクリック
   - または、「却下済み」の行をクリックして詳細を表示

## 方法2: 解決センターから確認

1. **解決センターを開く**
   - App Store Connectのトップページ上部のメニューから「**解決センター**」をクリック
   - または、URLに直接アクセス:
     ```
     https://appstoreconnect.apple.com/apps/{アプリID}/resolutioncenter
     ```

2. **通知を確認**
   - 「未解決」または「解決済み」のセクションを確認
   - サブスクリプションに関する通知を探す

## 方法3: メール通知を確認

1. **メールボックスを確認**
   - App Store Connectから送信されたメールを確認
   - 件名に「App Store Connect」や「サブスクリプション」が含まれるメールを探す
   - 却下理由が記載されている可能性があります

## 方法4: プロダクトページの警告を確認

1. **サブスクリプション詳細ページを開く**
   - 方法1の手順1〜4を実行

2. **警告アイコンを確認**
   - ページ上部に赤い警告アイコンや「**デベロッパの対応が必要**」というメッセージがある場合はクリック
   - 詳細な却下理由が表示される可能性があります

## よくある却下理由と対処法

### 1. 説明文が不充分
- **症状**: 説明文が短すぎる、または具体的な機能が記載されていない
- **対処**: 詳細な説明文に更新（`docs/サブスクリプション説明文.md`を参照）

### 2. サブスクリプションの期間が不明確
- **症状**: 「月額」などの期間が明記されていない
- **対処**: 「月額500円（税込）の自動更新可能なサブスクリプション」と明記

### 3. キャンセル方法が不明
- **症状**: ユーザーがキャンセル方法を理解できない
- **対処**: 「App Storeのアカウント設定からいつでもキャンセルできます」と追加

### 4. スクリーンショット不足
- **症状**: 画像がアップロードされていない（任意だが推奨）
- **対処**: 1024×1024ピクセルの画像を追加

### 5. 利用規約へのリンクがない
- **症状**: ガイドライン3.1.2違反
- **対処**: アプリ内に利用規約へのリンクを実装（既に実装済み）

## 確認できない場合

もし上記の方法で却下理由が見つからない場合は：

1. **App Store Connectのサポートに問い合わせ**
   - App Store Connect > ヘルプ > お問い合わせ

2. **説明文を改善して再提出**
   - `docs/サブスクリプション説明文.md`の改善案を使用
   - より詳細な説明文に更新して再提出

3. **スクリーンショットを追加**
   - 1024×1024ピクセルの画像を追加
   - サブスクリプションの価値を視覚的に伝える
