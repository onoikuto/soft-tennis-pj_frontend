# プライバシーポリシー公開手順

App Store ConnectでプライバシーポリシーURLを設定するための手順です。

## 作成したファイル

1. **`docs/privacy_policy.html`** - HTML形式のプライバシーポリシー
2. **`docs/privacy_policy_ja.md`** - Markdown形式のプライバシーポリシー

## 公開方法

### 方法1: GitHub Pagesを使用（推奨・無料）

#### ステップ1: GitHubリポジトリにプッシュ

```bash
cd /Users/ononono/soft-tennis-pj_frontend
git add docs/privacy_policy.html
git commit -m "Add privacy policy"
git push
```

#### ステップ2: GitHub Pagesを有効化

1. GitHubリポジトリ（https://github.com/ononono/soft-tennis-pj_frontend）にアクセス
2. 「Settings」タブをクリック
3. 左側のメニューから「Pages」を選択
4. 「Source」で「Deploy from a branch」を選択
5. 「Branch」で「main」または「master」を選択
6. 「/docs」フォルダを選択
7. 「Save」をクリック

#### ステップ3: URLを確認

数分後、以下のURLでプライバシーポリシーにアクセスできます：

```
https://ononono.github.io/soft-tennis-pj_frontend/privacy_policy.html
```

### 方法2: 既存のWebサイトにアップロード

既にWebサイトをお持ちの場合は、`privacy_policy.html`をアップロードしてください。

### 方法3: 無料ホスティングサービスを使用

以下のサービスも利用できます：

- **Netlify** (https://www.netlify.com/) - 無料
- **Vercel** (https://vercel.com/) - 無料
- **Firebase Hosting** (https://firebase.google.com/) - 無料

## App Store Connectでの設定

1. App Store Connectにログイン
2. 「マイApp」→「VALVE」を開く
3. 「App Privacy」セクションを開く
4. 「プライバシーポリシーURL」フィールドに、公開したURLを入力
   - 例: `https://ononono.github.io/soft-tennis-pj_frontend/privacy_policy.html`
5. 「保存」をクリック

## 確認事項

- [ ] プライバシーポリシーが公開されている
- [ ] URLが正しくアクセスできる
- [ ] App Store ConnectにURLを入力した
- [ ] 保存が完了した

## 注意事項

- プライバシーポリシーURLは、アプリの審査提出前に設定する必要があります
- URLは公開されている必要があります（認証が必要なページは使用できません）
- プライバシーポリシーの内容は、アプリの実際の動作と一致している必要があります
